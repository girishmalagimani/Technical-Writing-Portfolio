# Sample 1: Overview & How-to Guide

**Project**: ShopCPR End-User Platform Documentation

**Context**: ShopCPR is the digital storefront of the American Heart Association (AHA). It distributes training tools such as instructor guides, student workbooks, course completion cards, and multimedia assets. Comprehensive guidance was required to assist users with platform navigation and the checkout process.

**Achievements**: Developed clear, task-based procedural guidance to help end-users navigate the homepage, browse and filter product catalogs, evaluate product specifications, and complete purchases.

## ShopCPR End-User Platform Documentation

### Introduction

This guide provides task-based procedures for navigating the platform, browsing products, and completing orders.

### Homepage Overview

The ShopCPR homepage includes the following primary areas:

#### Header Navigation

* **ShopCPR Logo:** Select the logo to return to the homepage from any page.  
* **User Profile:** Manage account settings, view order history, and check active sessions.  
* **Search Bar:** Search for products by title, keyword, product code, or ISBN.  
* **Shopping Cart:** Review selected items and proceed to checkout.  
* **Language Selector:** Change the interface display language.

***Note**: The header elements remain pinned at the top across all pages.*

#### Top Navigation Menu

The Top Navigation Menu provides categorized access to the entire product catalog. Select categories from the top navigation menu to filter the product catalog:

* **All Products**: Displays the full product inventory.  
* **Courses**: Filters materials by course (such as CPR or ECC).  
* **Product Type**: Organizes items by format, including eBooks, print manuals, and digital videos.  
* **Topics**: Groups products by clinical subject, including BLS, ACLS, PALS, and First Aid.  
* **Instructor Materials**: Lists instructional resources designed for certified instructors.

#### Featured Content

Displays new releases, updated clinical guidelines, and featured products. Select any banner to open the product details page.

### Browse and Find Products

1. Select a category from the top navigation menu, or select **All Products**.  
2. Use the **Refine List** sidebar to filter results by:  
   * **Audience** (for example, Instructor or Student)  
   * **Format** (for example, Digital eBook, Print, Digital Video, or Online Course)  
   * **Product Type**  
   * **Associated Course**  
   * **Language**  
3. Review the product list in the main catalog pane. Each entry displays the product cover, title, ISBN, format tags, and price.  
4. To view more results, select a page number in the upper-right corner of the catalog pane

***Tip:** To locate an item directly, enter a keyword, ISBN, or product number in the search bar in the header.*

### View Product Details and Add to Cart

1. Select a product title from the catalog list to open its product page.  
   * The **Description** tab lists product contents, course alignments, and usage instructions.  
   * The **Product Specifications** tab lists system requirements, physical dimensions, and publisher metadata.  
2. In the **Quantity** field, enter the number of copies to purchase or select the up/down arrows.  
3. Select **Add to Cart**.  
    The cart drawer opens and displays the item summary, quantity, and subtotal.  
4. Choose one of the following:  
   * Select **Checkout** to enter payment and shipping details.  
   * Select **View Cart** to change item quantities or remove products.

# Sample 2: Product End-User Manual

**Project**: eReader Application User Manual

**Context**: Impelsys developed an eReader tool for the client, to which the client wanted an easy and usable end-user manual.  
**Achievements**: Delivered concise, task-based procedural guidance to help users navigate complex digital publications, manage persistent annotations (notes, highlights, underlines), create bookmarks, and configure accessibility/display settings.

## eReader Application User Manual

The eReader is a cross-platform digital reading platform, accessible on web and desktop environments. It provides tools to read, annotate, and study specialized medical publications and clinical guidelines.

### Open an eBook

The subscribed eBooks are accessible through supported web browsers and the desktop application.

* **Web Browser:** On the **My Shelf** page, select **Read Online** next to your eBook. The book opens in the eReader in a new browser tab.  
* **Desktop Application:** Select the downloaded eBook file from your library.

***Note:** The desktop application automatically reopens your eBook to the last page read.*

### Interface Overview

The eReader interface consists of three primary areas:

* **Toolbar:** Located at the top of the window; provides access to search, navigation, display settings, and bookmark controls. Point to any icon to display its tooltip.  
* **Reading Pane:** Displays the book content and interactive annotations.  
* **Seek Bar:** Located at the bottom of the window; tracks reading progress and jumps between chapters.

### Navigate Using the Table of Contents

> 1. On the toolbar, select **Table of Contents**.  
> 2. Select the arrow next to a section heading to expand sub-sections.  
> 3. Select any section title to jump directly to that page.

### Annotations and Notes

> 1. In the reading pane, select the text to annotate.  
>    A floating toolbar appears above the selection.  
> 2. On the floating toolbar, select **Note**.  
> 3. In the **Add Note** dialog box, enter your note. The application saves your changes automatically.  
>    A note icon appears next to the annotated text.  
> 4. Select the note icon to view, edit, or delete the note.

### Manage Bookmarks

> 1. Navigate to the page you want to mark.  
> 2. On the toolbar, select **Bookmark**, then select **Add Bookmark**.  
> 3. In the **Bookmark Name** box, enter a title (up to 40 characters).  
> 4. Select **Save**.

### Adjust Display Settings

From the toolbar, configure reading preferences:

* **Brightness:** Select **Brightness**, then drag the slider to adjust screen luminance.  
* **Font Size:** Select **Font (Aa)**, then drag the slider to change text size.  
* **Color Theme:** Select **Theme**, then choose **Light** or **Dark** mode.  
* **Full Screen:** Select **Maximize** to expand the window to full screen. Select **Minimize** to restore windowed viewing.
