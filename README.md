# Technical Writing Portfolio
## About This Repository

This repository contains curated technical writing samples authored by Girish Malagimani, showcasing structured authoring, topic-based information architecture, and end-to-end user documentation for enterprise and digital product platforms

### Included Samples

1. **ShopCPR End-User Platform Documentation**
   * **Format:** Overview & How-to Guide
   * **Domain:** Healthcare Training & E-Commerce Distribution (American Heart Association)
   * **Focus Areas:** Navigation hierarchy, catalog filtering workflows, and transactional checkout procedures designed to reduce user onboarding friction.

2. **eReader Application User Manual**
   * **Format:** Product End-User Manual
   * **Domain:** Cross-Platform Digital Reading & Educational SaaS
   * **Focus Areas:** Task-based feature guidance, annotation workflows (notes, bookmarks), interface customization, and accessibility controls.

### Methodology & Standards

* **Style Governance:** Strictly aligned with the Microsoft Manual of Style (MSTP) for tone, terminology, and clarity.
* **Architecture:** Developed using topic-based authoring principles, separating conceptual overviews from task-oriented procedural steps.
* **Delivery:** Built using a Docs-as-Code workflow with standard Markdown formatting, version-controlled via Git/GitHub.
